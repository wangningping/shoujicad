在现场问一句「这个尺寸是多少」，往往要先找到电脑、装上软件、等图纸打开。如果图纸在微信里传了一圈，还能在手机上直接打开、放大、量一下，这件事就省了很多来回。

这是一个为这种场景做的工具：**一个纯前端、可离线安装的 CAD 查看器**。它只做一件事——把 DXF / DWG 图纸放进手机浏览器，让人能看、能量、能转。没有编辑、没有账号、没有云端上传。

**一、图纸留在你的设备上**

打开方式很朴素：点「导入图纸」选择本机的 `.dxf` 或 `.dwg`，支持多选；也可以点「加载示例」直接看内置图纸。解析全部在浏览器里完成，文件不会发送到任何服务器。

DWG 的支持来自 LibreDWG 的 WebAssembly 移植，约 7.8 MB 的 WASM 资源随应用一起打包。首次加载后被 Service Worker 缓存，之后再打开图纸不需要联网——工地没信号的地下层、隧道里，同样能用。

**二、为手指设计的看图方式**

交互沿用常用 CAD 看图软件的手感，但按手机重新排过：

- 单指平移，双指缩放与旋转；滚轮缩放留给桌面端。
- 底栏只留高频项：放大 / 缩小 / 全图 / 测距 / 图层，以及收起旋转、夜间画布的「更多」。
- 左转 15°、右转 15°、回正 0° 放在浮层里，连续旋转时浮层不会自动收起，不用反复点开。双指旋转始终可用，是一个不退化的兜底。
- 横屏时底栏按钮压到 44 px、浮层改两列，避免被画布裁切。
- 宽屏（≥1181 px）下图层面板改为右侧常驻，底栏里的「图层」按钮自动隐藏，同一个功能只有一个入口。

缩放比例和角度固定在画布左下角，量图时不用去猜当前状态。

**三、测量不是摆设**

看图软件里的测量常常只是画条线。这里的三个工具都按真实几何计算：

- **测距**：轻点两点，显示长度与方位角，例如 `741.69 mm · 308.4°`。
- **半径**：轻点圆或圆弧即选中，显示 `R 30.00 mm`；圆弧只高亮自身扫掠范围，不会把整圆画出来。
- **夹角**：依次点两条直线，在交点处画角弧并标注度数；第一条落定后会提示「已选 1/2」。

按住对象时结果就实时预览，松手才落定；预览比正式结果略淡，不容易误认。被量的对象用青绿描边加光晕，量出的数值统一用琥珀色——「量的是什么」和「量出多少」在颜色上就分开了。

单位读取 DXF 的 `$INSUNITS` 映射为 mm / cm / m / in / ft；图纸没标注单位时显示「单位未标注」，不臆造。点空白、点错、重复点同一条线、两条线平行或重合，都会给出中文提示，不会留下一个看起来像结果的错值。

**四、拖动端点时，它会吸附到几何点**

测距模式下按住任一端点就能拖动，手指不离开手柄时画布不会跟着平移。拖动或落点时会自动捕捉附近的端点、交点、圆心、中点、象限点与线上近点，吸附半径 14 px，落点精确贴到几何坐标。

这里踩过几个细节：优先级是端点 > 交点 > 圆心 > 中点 > 象限点 > 近点，并叠加距离惩罚，避免远处顶点抢走手边更准的中点；近点只在 6 px 内生效，防止密集图纸「处处吸附」；捕获 14 px、释放 20 px 形成滞回，指尖在阈值边缘微动不会反复跳；按下时的原锚点在离开其捕捉圈前不参与吸附，端点不会被自己「粘住」。

命中后会画出方、三角、圆、菱形、叉等标记并附中文标签，能直接看出吸附到了哪一类点。

**五、夜间画布与图层**

底栏「更多 → 夜间画布」切到深色底 `#18222f`，白色线条配琥珀色测量标注，长时间在暗处看图更舒服。切换不需要重新解析图纸——浅色和夜间两套颜色在解析时就同时生成了。

图层面板可以逐个开关图层；「信息」里给出文件名、格式、图层数与图元统计，以及未支持图元的类型清单。这些都属于看图的辅助信息，不挤占主操作区。

**六、装到手机上**

项目构建出的 `dist/` 是可直接部署的静态站点，`base: './'` 允许放在子路径下。PWA 清单和 Service Worker 已配好，浏览器里点「添加到主屏幕」即可离线打开。

需要原生体验的话，`npm run android:apk` 会把同一份 Web 构建用 Capacitor 打包成 Android debug APK，应用外壳与 DWG 的 WASM 全部内置，首次导入 DWG 不依赖网络。

**七、开源与许可证**

代码在 GitHub：`https://github.com/wangningping/shoujicad`

技术栈是 Vue 3 + Vite + TypeScript，DXF 解析用 MIT 许可的 `dxf-parser`，渲染是自研 Canvas2D，不依赖闭源 CAD 内核、不接在线转换服务。

需要提醒的是：**DWG 路径依赖 GPL-3.0 的 `libredwg-web`**。如果对外分发包含 DWG 功能的应用，需按 GPL-3.0 履行相应义务；只用 DXF 路径时，依赖均为 MIT。这一点在 README 里也写清楚了。
