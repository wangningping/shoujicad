# 移动端 CAD 查看器（基础版）

纯前端、可离线安装的 DXF / DWG **查看**应用。手机与平板共用一套界面：窄屏为抽屉式面板，宽屏为左右停靠栏。不含编辑、协同、账号、上传云端等非查看功能。

## 1. 技术选型与许可证

| 组件 | 版本 | 许可证 | 用途 | 选型理由 |

| [@mlightcad/libredwg-web](https://github.com/mlightcad/libredwg-web) | 0.9.2 | **GPL-3.0** | DWG 解析（WASM） | LibreDWG 官方 WebAssembly 移植，持续发布，覆盖 R13–R2018+ DWG |

## 2. 环境要求

- Node.js `^20.19.0 || >=22.12.0`（Vite 8 要求）
- 现代浏览器：Chrome / Edge / Safari 16+（需 Pointer Events、IndexedDB、ES2022）
- 移动端：iOS Safari 16+ / Chrome Android 100+
- 构建 APK 额外需要：JDK 21、Android SDK（platform 36 / build-tools 36）、Gradle Wrapper（首次构建会自动下载 8.14.3）

## 3. 快速开始

```bash
npm install
npm run dev            # 默认 http://localhost:5173，局域网可用 --host
```

打开页面后点击「加载示例」即可查看内置 DXF；也可点击「导入图纸」选择本机 `.dxf` / `.dwg` 文件（支持多选）。

生产构建与本地预览：

```bash
npm run build          # vue-tsc 类型检查 + Vite 构建
npm run preview        # 预览 dist/
```

`dist/` 可直接部署为静态站点。`base: './'` 使其可放在子路径下；DWG 的 WASM 资源由 Vite 自动产出到 `dist/assets/`，由 Emscripten glue 通过 `new URL(..., import.meta.url)` 定位，无需手工复制。Service Worker 会预缓存应用外壳，并在首次加载后缓存 `.wasm`。

生成 Android debug APK（产物：`android/app/build/outputs/apk/debug/app-debug.apk`）：

```bash
npm run android:apk        # 构建 Web 资源 → cap copy android → Gradle assembleDebug
npm run android:install    # adb install -r（需先连接真机并开启 USB 调试）
```

APK 使用 debug 签名，直接安装到真机测试；应用外壳与 7.8 MB 的 DWG WASM 全部内置，首次导入 DWG 不依赖网络。

## 5. 实现要点

- **统一数据模型**：DXF / DWG 都归一化为 `CadDocument { layers, entities, bounds, entityCounts, unsupported }`；渲染层不感知来源格式。
- **支持图元**：LINE、LWPOLYLINE / POLYLINE（含凸度圆弧段）、CIRCLE、ARC、ELLIPSE、TEXT、MTEXT、POINT、SOLID / TRACE、SPLINE 控制点折线；DXF 的 INSERT 会展开 BLOCK 内的实体（最大递归深度 3）。
- **颜色**：ACI 色号与真彩色统一映射为 CSS 颜色；图层色为默认，实体可覆盖。ACI 7/8/9 随画布底色反转，解析时同时生成浅色与夜间两套颜色，切换无需重新解析。
- **看图界面**：参考 CAD快速看图 的交互习惯，工具条置于画布底部并采用「图标 + 中文标签」，顶部显示当前图纸名与格式，缩放/旋转状态在画布左下角。
- **工具分层**：底栏只放高频项，`放大 / 缩小 / 全图 │ 测距 / 图层 / ⋯ 更多`。旋转（左转、右转、回正）、夜间画布收进「更多」浮层，浮层贴底栏右端向上弹出、全程在拇指弧内，连续旋转不会自动收起，点画布空白处或按 Esc 关闭。旋转本身有双指手势兜底，降级不损能力。
- **入口归属**：按「操作对象」而非「屏幕位置」分配，任何断点下同一功能只有一个入口。
  - `图层` 属画布操作（与测距同族、读图过程中反复开关），只留在底栏；顶栏不再放同名按钮。≥1181px 时右栏常驻图层面板，底栏的「图层」自动隐藏。
  - `信息` 属文档级元数据（文件名、格式、图层数、图元统计），只留在顶栏，窄屏为 34px 图标按钮（`title` / `aria-label` 为「图纸信息」），≥1181px 由右栏 InfoPanel 承担。原「更多 → 图纸信息」已移除，浮层只保留视图显示项。
  - 底栏宽度固定上限 448px 并居中，不再随屏幕拉满：393px 机型单项 50px，横屏 752px 时单项 76px，均高于 44px 安全线；≥1181px 时右栏已常驻图层面板，底栏自动隐藏「图层」。
  - 横屏（高度 ≤480px）单独压缩：底栏按钮 44px、「更多」浮层改两列，避免浮层被画布容器裁切。
- **相机**：世界坐标 → 屏幕坐标的显式变换，缩放/旋转均围绕指定锚点；单指平移、双指缩放旋转、滚轮缩放、±15° 按钮旋转、适合窗口。
- **测量**：底栏的测量按钮会显示当前工具（`测距 / 半径 / 夹角`），点一下进入、再点退出；三把工具的切换在「更多 → 测量」分段控件里，选完浮层自动收起。可连续测量，计数与「清除」在左下状态条上（不插入底栏，避免按钮挤位漂移）。拖动仍可平移，双指仍可缩放旋转。测量结果仅存在于当前会话，不写回图纸。
  - **测距**：轻点两点，标签显示长度与方位角（如 `741.69 mm · 308.4°`）。
  - **半径**：轻点圆或圆弧即选中（拾取半径 18px），标签显示 `R 30.00 mm`；圆弧按自身扫掠范围高亮，不会把整圆画出来。
  - **夹角**：依次点选两条**直线**，交点处画角弧并标注度数（`90.0°`）；先选的那条会显示「已选 1/2」，第二条落定后自动求解。
  - **实时预览**：手指按住对象就开始出结果（桌面端鼠标悬停即可），松手才落定；预览比正式结果略淡，避免误以为已完成。
  - **高亮与配色**：被测量对象用青绿描边 + 光晕标出，测量线/弧/标签统一用琥珀色——「量的是什么」与「量出多少」用颜色分开。
  - **单位**：读取 DXF `$INSUNITS` 映射为 `mm / cm / m / in / ft` 等，标签与状态条同时给出；未标注（`$INSUNITS=0` 或 DWG 未提供）时不臆造单位，状态条显示「单位未标注」。
  - **无效选择**：点空白、点错对象、重复点同一条线、两条直线平行/重合，都会在底栏上方给出中文提示且不产生测量；提示与状态条分离，不会压住百分比读数。
- **端点拖动与对象捕捉**：测距模式下按住任一端点（20px 命中范围）即可拖动，指纹离开手柄前不会平移图纸；拖动或轻点落点时自动捕捉附近几何点——端点、交点、圆心、中点、象限点、线上近点，捕捉半径 14px（屏幕像素，缩放时手感一致）。命中后端点精确贴到几何坐标并实时刷新长度/角度，落空则保持自由拖动。
  - 优先级：端点 > 交点 > 圆心 > 中点 > 象限点 > 近点，同时叠加距离惩罚，避免远处顶点压过手边更精确的中点；近点只在 6px 内生效，防止密集图纸「处处吸附」。
  - 防误吸附：按下时的原锚点在手指离开其捕捉圈之前不参与吸附，端点不会被自己「粘住」拖不动。
  - 防抖动：捕获半径 14px / 释放半径 20px 形成滞回，指尖在阈值边缘微动不会反复切换；仅当更高优先级候选进入 0.75 倍半径时才允许接管（从边线滑到顶点），同优先级之间不回跳。
  - 反馈：捕捉点按类型绘制方/三角/圆/菱形/叉等标记并附中文标签，拖动中的端点显示放大的实心手柄光环；已吸附端点带细环，可直观看出测量确实落在几何点上。
- **夜间画布**：底栏「更多 → 夜间画布」切换；深色底使用 `#18222f`，白色线条与高亮橙测量标注保证可读性。
- **性能**：`requestAnimationFrame` 合并重绘；DPR 上限 2；DWG 的 7.8 MB WASM 仅在首次导入 DWG 时动态加载，不阻塞 DXF 路径。
- **持久化**：IndexedDB 保存原始文件字节、解析结果与缩略图；刷新后图纸列表保留。原文件仅用于留存，不做写回。

## 6. 基础验证

```bash
npm run typecheck   # 类型检查
npm run build       # 类型检查 + 生产构建
npm run verify      # Node 端解析 public/samples/demo.dxf，检查图层/图元类型/包围盒/WASM 产物
npm run verify:snap # Node 端跑对象捕捉回归：优先级、交点/近点、抑制锚点、锁定接管、隐藏图层、性能
npm run verify:measure # Node 端跑测量回归：夹角计算、直线求交、平行判据、圆/弧/线拾取、单位格式化、真实图纸端到端
npm run dev         # 然后浏览器打开 http://localhost:5173/scripts/browser-smoke.html
```

`browser-smoke.html` 会逐项输出 PASS/FAIL：DXF 解析数量、图层、包围盒、Canvas 实际绘制像素数、浅色/夜间双模式颜色、夜间画布反向着色、测距长度/方位角计算、半径/夹角叠加层（对象高亮 + 标注）、浅色与夜间测量叠加层、捕捉索引/优先级/交点/近点/抑制锚点/锁定滞回/指示器绘制、DWG WASM 可加载。`snap-check.mjs` 覆盖同样的判定逻辑（不依赖 DOM），并附 2.5 万条线段的性能基线。另可在手机尺寸（如 390×844）打开首页，确认「加载示例 → 底栏测距 → 更多里切半径/夹角 → 点对象测量 → 更多 → 夜间切换 → 双指缩放/旋转 → 底栏图层开关 → 顶栏信息」链路。

已实测结果：示例 DXF 解析出 21 个图元、5 个图层，Canvas 绘制 5817 个非背景像素；夜间画布背景为 `24,34,47` 且有 4919 个亮像素；测距叠加层绘制 382 个标注像素，夜间高亮 497 个；以 LibreDWG 测试夹具 `leader_2013.dwg`（AC1027）验证 DWG 路径，解析出 3 个图元并正常渲染。

## 8. 已知边界

- 仅查看：不支持保存修改、打印导出、块编辑；测量结果是会话内的临时叠加层，不写回 DWG/DXF 文件。
- 夹角只接受 `LINE` 实体：多段线、样条各段方向不唯一，强行测角会得到没有意义的结果，因此不参与夹角拾取（点它会给提示）。
- 半径/夹角的拾取是线性扫描全部图元（单次约 1ms / 2 万图元），图纸规模再上一个量级时需要像捕捉那样建空间索引。
- DWG 路径暂未解析单位，标签只给数值，状态条显示「单位未标注」。
- 图纸自带的 DIMENSION 实体目前未渲染，其数值不会被测量工具自动读取；未支持的实体（如 DIMENSION、LEADER、HATCH、样条精确曲线等）会在信息面板按类型计数并在渲染时跳过，不会导致导入失败。
- 文字使用浏览器字体近似渲染，不加载 CAD 的 SHX 字体文件。
- DWG 版本兼容性取决于 LibreDWG；极新的文件格式可能解析失败或降级显示。
- 大图纸的实体全部驻留内存，基础版未做空间索引与分块渲染。
